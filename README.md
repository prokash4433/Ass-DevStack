🚀 DevStack – Technology Stack Manager

DevStack is a simple and interactive technology stack management website built with React. Users can explore different technologies, add their favorite technologies to their own stack, remove individual items, and clear the entire stack.

🌐 Live Demo

🔗 Live Website:  https://splendorous-hummingbird-718484.netlify.app/

🔗 GitHub Repository:  https://github.com/prokash4433/Ass-DevStack

📌 About The Project

DevStack helps users explore different web development technologies and create their own personalized technology stack.

The project has a clean, responsive, and user-friendly interface. Users can add technologies to their stack and manage them easily with interactive buttons and toast notifications.

🛠️ Technologies Used
⚛️ React.js
🎨 Tailwind CSS
🌼 DaisyUI
🟨 JavaScript (ES6+)
🔔 React-Toastify
📄 JSON – Used for technology data
⚡ Vite – Used as the build tool


Features-
1.  Browse Technologies:
Users can view different technologies with information such as name, category, description, icon, and rating.

2.  Add & Remove Technologies:
Users can add technologies to Your Stack and remove them whenever they want.

3.  Interactive User Experience:
The project provides toast notifications when technologies are added or removed, making the interface more interactive and user-friendly.





React Questions & Answers...?
1. What is JSX, and why is it used in React?

-JSX lets us write HTML-like code inside JavaScript. It makes React code easier to read and write.

2. What is the difference between props and state?

-Props are used  pass data from parent to child. State is used  manage data  can change inside a component.

3. What does the useState hook do, and where did you use it in this project?

-useState is used to manage changing data. I used it to manage the technologies added to your stack.

4. What does the useEffect hook do, and why did you need it to load the JSON data?

-useEffect runs side effects in React. i used it to load the technology data from the JSON file.

5. Why does every item in a .map() list need a unique key prop?

-A unique key helps React identify each item and update the list correctly.

6. What is conditional rendering? Show one place you used it.

-Conditional rendering means showing something based on a condition. I used it to show an empty stack message when there are no technologies in the stack.

7. How do you pass data from a parent component to a child component, and how does a child send something back to the parent?

-A parent sends data to a child using props. The child can send something back by calling a function passed through props.
